# PrintCheck Vision C3B.3.I — проверка PNG-отпечатков по исходным байтам

Дата: 2026-11-17. Текущий статус: **исследовательский закрытый контур**, никаких изменений основной «Макетной» и никаких реальных customer assets в публичном GitHub.

## Исправленный источник недостоверности

В C3B.3.G/H подписанный Ed25519 cohort содержал image_sha256, artwork/family SHA, split и готовый visual fingerprint для каждого заказа. Наличие подписи на JSON подтверждает целостность утверждения подписанта, но **не доказывает, что визуальный отпечаток действительно вычислен из исходного PNG**. Подписант мог получить чужой fingerprint, случайно ошибиться в порядке изображений или просто подменить градиент при формировании манифеста.

Новый этап пересчитывает весь визуальный fingerprint самостоятельно из **оригинальных байтов приватного изображения**. Для research metrics одного подписанного JSON теперь недостаточно. В locked-pilot gate обязательно проверяются все изображения cohort, а не только один task, относящийся к конкретному тестовому заказу.

## Исполняемые модули

- `vision/dataset/strict-png-decoder.mjs` — автономный детерминированный Node декодер PNG с проверкой заголовка, CRC-32 каждого chunk, обязательных IHDR/IDAT/IEND, порядка IDAT, размеров, budget сжатых/распакованных данных, Paeth и scanline filters 0–4. Выдаёт RGBA, не зависит от браузерного цветоуправления.
- `vision/dataset/cohort-image-provenance.mjs` — проверяет ровно по одному исходному изображению на каждый entry signed cohort: SHA-256 raw PNG, декодирование, пересчёт полной структуры fingerprintRgba (dimensions, bbox, ink fraction, все восемь ориентаций silhouette и gradient), сравнение с подписанным JSON. Если хоть один элемент не совпал, MANUAL.
- `vision/dataset/locked-pilot-gate.mjs` — дополнен обязательным `cohortImageBytes` с изображениями в том же порядке, что cohort.entries. Сверяет подписанный cohort, оригинал исходного SVG/PDF, доказательства и слепое sampling plan; исследовательский eval без исходных PNG больше не разрешается.
- `vision/dataset/verify-cohort-images.mjs` — отдельно запускаемый **потоковый по файлам** приватный аудитор: выполняет проверку подписанного cohort, затем читает изображения последовательно, не собирая их в один гигантский массив и не раскрывая имён и SHA в stdout. Статус исследования; никаких network requests.
- `tests/helpers/synthetic-png.mjs` — тестовый генератор PNG, не содержащий реальных макетов.
- `tests/printcheck-vision-strict-png.test.mjs`, `tests/printcheck-vision-image-provenance.test.mjs`, `tests/printcheck-vision-cohort-files.test.mjs` — новые негативные тесты и тесты целостности.

## Поддерживаемые входы — намеренно ограничены

**Автоматически:** PNG 8 bit/channel, grayscale, grayscale+alpha, truecolor RGB, RGBA; noninterlaced; без цветовых профилей. PNG chunk CRC, размеры и inflate output limit проверяются.

**MANUAL:** JPEG/WEBP/AVIF, indexed/palette PNG, 1/2/4/16-bit, interlaced PNG, цветовое управление gAMA/sRGB/iCCP/cICP/cHRM и APNG/прозрачность tRNS, неизвестные критические chunks, некорректная CRC, слишком большое/повреждённое изображение. Это осознанно консервативный исследовательский декодер, **не полноценная реализация всех возможностей PNG**. Профили цвета и другие форматы нельзя просто проигнорировать при интерпретации реального цвета печати.

Пределы: вход PNG до 25 MB, распакованный RGB/RGBA до 12 миллионов пикселей, массив cohort до 1024 entries; отдельный CLI читает файлы по одному. Предсказания print-scale из PNG запрещены: изображение 192×192 не доказывает физическую толщину 0,15 мм.

### Независимый audit signed cohort из приватной среды

Нужны:

- `cohort.json` — raw bytes ранее подписанного frozen cohort из C3B.3.G/H.
- `cohort.sig` — Ed25519 подпись точных байтов cohort.json.
- `auditor-public.pem` и **независимо закреплённый** SHA256 DER SPKI открытого ключа (не доверять pin из той же непроверенной папки).
- Приватный список путей `preview-paths.json` с полями schema и ordered_paths, где порядок в точности соответствует cohort.entries. Не помещать в репозиторий, CI или чат:

    {
      "schema": "printcheck.vision.preview-paths.local.v1",
      "ordered_paths": [
        "/secure/cohort/train-001.png",
        "/secure/cohort/test-002.png"
      ]
    }

После определения правильных приватных путей запустить:

    node vision/dataset/verify-cohort-images.mjs cohort.json cohort.sig auditor-public.pem PIN_SHA256 preview-paths.json

Результат сообщает только status, checked_images, checked_compressed_bytes, boolean source verification и границу доверия. Никакие изображения, номер заказа, пути, SHA, fingerprint, секретный seed и приватные ключи не выдаются в stdout. Если любой файл подменён, повреждён, отсутствует, является symlink или не поддерживается — ошибка MANUAL, exit status 2.

Данный CLI валидирует **криптографическую связь подписанного набора с фактическими PNG**, но не подлинность Gifts.ru как источника и не физические размеры. Отдельный источник заказа и масштаб остаются предметом независимой подписи технолога по C3B.3.F.

### Логика исключения cross-split leakage

Только после успешной проверки всех исходных PNG можно опираться на предварительное расстояние их silhouette/gradient fingerprints. Near-duplicate detector всё ещё способен ошибаться; подозрительные пересечения train/validation/test автоматически блокируются, но «чистый» результат означает только, что **конкретный скрининг не выявил известных ему совпадений**. Это не математическое доказательство уникальности логотипов.

Искусственный Ed25519 key и синтетический PNG тест демонстрируют работоспособность контракта, но не заменяют настоящую независимую экспертизу.

## Измерения и примечания по производительности

- PNG разбирается один раз и преобразуется в RGBA. Перцептивный fingerprint считается поверх локального RGBA, без второй независимой реализации / canvas, что обеспечивает воспроизводимость.
- Декомпрессия ограничена maxOutputLength ожидаемых scanlines; oversized images и unsupported decoding не пропускаются в evaluator.
- Отдельный CLI загружает **только текущий файл** cohort, что уменьшает пиковую память относительно загрузки всех заказов одновременно.
- Двухфакторной/программной верификации происхождения заказа по API Gifts.ru в этом цикле нет; customer data не использовались.

## Внешние спецификации

- W3C PNG Third Edition (Recommendation, 24 June 2025): https://www.w3.org/TR/png-3/
