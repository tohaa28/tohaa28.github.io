# Административные настройки нанесений

Открытие — Alt+N (физическая клавиша N, работает и в русской раскладке), повторное нажатие закрывает окно. Вход admin/admin. При обычном запуске окно закрыто; авторизация не сохраняется между открытиями. Escape, крестик и «Отмена» закрывают панель без применения черновика. Сохранение применяет настройки к текущим размещениям и их диагностике.

Изучен чат «Исправление HTML JavaScript» (6a9ffee3-4e74-83eb-8353-05e787a36242) и приложенный index (2).html: скрытые настройки при запуске, открытие по горячей клавише, проверка хеша пароля, отдельный draftConfig, сохранение/отмена. Здесь Alt+N сразу открывает вход, согласно текущему запросу пользователя. Панель реализована как dialog, с принудительным display:none для закрытого состояния; её авторизация локальная, не серверная.

Параметры хранятся в localStorage `gwb-method-settings-v1` на текущем origin (gifts.ru для закладки). Между компьютерами/браузерами автоматически не синхронизируются. Экспорт/импорт JSON переносит конфигурацию; импорт сначала загружает черновик, применение — после сохранения. Все методы и параметры проверяются по схеме, отрицательные/бесконечные пороги, неизвестные коды, неизвестные проверки и неверные типы отклоняются. Ошибка хранилища не выдаётся за успешное сохранение.

Исходная PRINT_REQUIREMENTS остаётся неизменной и соответствует документированной карте gifts.ru. `configureRule(effectiveRule(...))` применяет пользовательские overrides последними. Охранное поле, включая длинную/короткую сторону, по умолчанию 0 мм для всех 92 кодов. Пользовательское положительное охранное поле измеряется от границы выбранного нанесения. Старые общие guard/minDpi в скрытом подробном редакторе заменены настройками по коду и больше не добавляют отдельные блокировки экспорта.

Есть общий выключатель метода и отдельные группы: шрифты, эффекты, скрытые объекты, dpi, цветность, позитив, негатив, отдельные элементы, PrintCheck, граница поля, охранное поле, вылеты, контуры, дополнительные условия. Отключённые findings не участвуют в блокировке экспорта; отчёт явно указывает отключение/пользовательские настройки и не становится productionApproved. Структурная проверка соответствия мест заказа и printN остаётся независимой.

Изменение настроек обновляет результаты и кнопки экспорта. Отключение PrintCheck/метода удаляет ключ размещения из очереди, отменяет текущий worker и убирает устаревшие маркеры. Изменённые пороги входят в ключ кеша. Отключение позитивов/негативов/отдельных объектов передаёт в анализ нулевой порог соответствующего типа.

Проверки: 60 unit tests; browser regression — неверный/верный вход, 92 кода, черновик/отмена, изоляция методов, guard 0 и override 1000, цветность и экспорт, выключение метода и worker, import/export/невалидный JSON, загрузка сохранённой конфигурации в новом окне, Alt+N/Escape. Прежние field/clip/printN/rotation/zoom тесты сохранены.
