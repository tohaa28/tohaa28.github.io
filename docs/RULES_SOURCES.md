## 2. Каталог 30 проблем

Источник — vision/rules/problems.v1.json. Стабильные коды PC-001 — PC-030 связаны с отдельными URL статей Gifts. Возможные способы проверки помечены deterministic или hybrid. Все категории имеют implementation=planned: готового детектора нет, и реальное производственное использование запрещено.

Требуемая трасса результата: PC-код → rule_id → revision → source URL → технология → конструктор/заказ → физический масштаб → измерение → доказательство.

## 4. Приоритет требований и конфликт источников

Применимость: подтверждённое требование конкретного заказа имеет приоритет перед подтверждённым требованием конструктора, которое имеет приоритет перед стандартным технологическим справочником.

Для override обязательны идентификатор точного заказа/конструктора, метрика, технология, утверждение специалиста, исходный документ и его SHA-256. Обычный текст PDF не считается утверждённым правилом.

Известный конфликт GFT-CONFLICT-DECAL-PALETTE: текущие общие спецификации для H1–H3 упоминают допуск 25%, в статье о проблемах деколи встречается 15%. Для max_pantone_deviation_percent до решения технолога статус MANUAL. Обе ссылки и числа сохранены в source_conflicts.

Три статуса:
- ERROR — доказанный размер меньше применимого минимума;
- OK — доказанный размер достигает минимума, но только по конкретной метрике, не всему макету;
- MANUAL — неизвестный масштаб или геометрия, нет правила/условия, измерение близко к порогу с неопределённостью, конфликт правил или нет экспертного согласования.

При 0,150 ± 0,001 мм с минимумом 0,150 мм результат MANUAL. Нейросеть не вправе изменить ERROR на OK.

## 5. Безопасность и проверки

Детерминированный механизм: vision/rules/resolver.mjs.
Тесты: tests/printcheck-vision-rules.test.mjs.

Реестр пока experimental_not_production_approved. Вызов в обычном режиме не выдаёт технологический допуск: RULESET_NOT_APPROVED. Исследовательская проверка требует research_mode=true и scale_proven=true, geometry_proven=true.

Архивы предыдущих версий PrintCheck — источник примеров и гипотез, не истины. Истинные метки назначаются только экспертами. Приватные PDF/ZIP запрещено публиковать в открытом репозитории.

## 6. Критерии допуска новых правил

Перед production_approved требуется повторная сверка полного списка нормативов с Gifts.ru, согласование технологом, верификация кода и поверхности/материала, точная векторная геометрия в мм, регрессионные тесты и независимая слепая проверка на архивных макетах по группам исходных заказов. Никаких автодопусков на основе старой диагностики или необученной модели.
