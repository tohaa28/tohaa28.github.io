# PrintCheck Vision — C3B.3.D: криволинейные элементы и независимая оценка

Дата: 2026-11-16. Статус: **исследовательский подцикл**, не готовый производственный PrintCheck. Изоляция: draft PR #4, Issue #5.

## 1. Что добавлено

**vision/geometry/curved-normal-probes.mjs** — локальные кандидаты ширины краски и отрицательных промежутков на *подтверждённо замкнутых* векторных контурах. Метод отличается от уже существующих строго параллельных прямых стенок: каждая исследуемая точка на краю сравнивается с ближайшим пересечением нормального луча и противоположной векторной границы. Измерение разрешается только при устойчивом трёхсегментном окне.

Обязательные условия:
- предварительно успешная топология от inspectVectorCorridors; пересекающиеся, самокасающиеся и вырожденные контуры заблокированы;
- физическая матрица SVG/PDF → мм передана явно, но её истинность для заказа *не считается аттестованной*;
- три соседних звена границы должны иметь достаточно длинный суммарный поддерживаемый участок и не образовывать резкого угла;
- ближайшая противоположная стена не может быть соседней вершиной того же контура; пересечение у конца чужого звена или касательное попадание недостаточно достоверны;
- проверяются значения ширины в трёх позициях. При существенном изменении толщины (клиновидное окончание/засечка) измерение отбрасывается;
- середина поперечного отрезка проверяется правилом evenodd и классифицируется отдельно как positive_width_mm или negative_gap_mm;
- всякие ограничения бюджета и недостоверные входы дают MANUAL; количество кандидатов при обрезке отмечается как truncated. Пропуски между пробами **возможны**, поэтому результат НЕ глобальный минимум.

По умолчанию окно поддержки 0,2 мм, углы плавного перехода 26°, близость касательных двух стен 32°, допустимое относительное изменение ширины 12%, диапазон поиска до 2 мм. Это **параметры исследовательской геометрии**, а не нормы Gifts.ru.

**Интеграция только по явному запросу:** существующие svg-dom-vector-bridge.mjs и pdfjs-vector-bridge.mjs могут быть вызваны с include_curved_probes=true. Они возвращают отдельно curved_probes; старые candidates и старый алгоритм не изменены. Если анализ контура не поддержан, весь дополнительный анализ возвращает MANUAL, а не частичный фальшивый OK. Не меняются ни производственный редактор, ни стандартный запуск Vision.

## 2. Архивы: действительно проверенные факты

На **локально доступных четырёх ZIP**, без публикации их содержимого/имён файлов:
- 167 файловых записей обработано потоковым SHA-256; 162 уникальных блока данных, 5 точных дубликатов; общий объём 55 048 723 байта;
- в двух основных архивах найдено суммарно 54 PDF и 31 PNG; ещё два архива содержат служебные тестовые файлы;
- опасных путей для извлечения не выявлено;
- **0 независимо подтверждённых меток специалиста** получено в данном цикле. Наличие отчёта PrintCheck не является настоящей экспертной оценкой. Поэтому precision/recall на реальных заказах пока нельзя рассчитывать.

Эти цифры не характеризуют весь архив истории заказов, только 4 фактически доступных ZIP. Не включать имена заказов/оригинальные PDF/PNG или SHA в публичный GitHub.

## 3. Инструмент для будущего слепого сравнения

**vision/dataset/evaluate.py** — самостоятельная offline Python stdlib утилита для строгих *региональных* меток, а не автоматического вывода о целом макете.

Принимает JSON schema printcheck.vision.expert-regions.v1:
- artwork_sha256, region_sha256 и family_sha256, где family объединяет все изображения одной исходной работы/заказа;
- разбиение train/validation/test с запретом попадания одного family/artwork в разные группы;
- подтверждённую специалистом метку defect/acceptable + хеш аннотации и ссылочного идентификатора рецензента;
- статус алгоритма candidate/none/manual и его revision.

Отклоняет неподтверждённые экспертные метки, метки из автоматической диагностики, отсутствующие источники, дубли регионов, пересечение групп и некорректные размеры данных. **Форматные хеши не являются криптографическим доказательством личности рецензента**; в будущем понадобится отдельная система подтверждения подписей.

На выходе только агрегатные показатели: coverage, manual abstentions, precision/recall среди разрешённых регионов, FP/FN, технологические группы не менее пяти регионов. Номера заказов, имена, хеши, пути, клиентские изображения и индивидуальные результаты не включаются. Файл отчёта создаётся без перезаписи с правами 0600. Сами архивы не открываются этой утилитой — экспертные области подготавливаются отдельно в приватной среде.

**Важно:** метрика «точность кандидатов геометрии» НЕ является «точностью заключений о пригодности макета». Задача технологического допуска по всей площади, цветам и методу печати остаётся открытой.

## 4. Проверки / параметры

- tests/printcheck-vision-curved-normals.test.mjs — 10 сценариев: концентрические кольца, плавные синусоидальные полосы, отрицательный зазор, изменения масштаба, острые концы, пересечения, недостаток точности/лимитов, запрет автоматического допуска.
- tests/printcheck-vision-pdf-bridge.test.mjs и tests/printcheck-vision-svg-dom.test.mjs — по одному интеграционному тесту самостоятельного вызова curved_probes из PDF и SVG.
- tests/test_printcheck_vision_evaluate.py — 11 сценариев независимой оценки, включая leakage через artwork или family, ложно «экспертные» метки, дубли и отсутствие идентифицирующих полей в отчётах.
- tests/bench-printcheck-vision-curved.mjs — воспроизводимые синтетические 48/96/192/384 сегмента, медианы CPU без неустойчивых порогов. Не содержит заказов.

GitHub Actions держит отдельный rule-gate и browser UI smoke; опубликованные результаты указаны в docs/DEVLOG.md.

## 5. Технологические ограничения и следующая фаза

**Не заявляем:** полного извлечения PDF/SVG, точного medial axis / distance transform, математически гарантированного глобального минимума толщины, правильной интерпретации острых засечек без семантики формы, подтверждения исходной матрицы миллиметров по заказу, ML-модели или точности на реальных заказах.

**Следующий цикл C3B.3.E:** авторизованная экспертная разметка узких областей в приватной студии; контроль ложноположительных острых элементов; независимый региональный truth set без leakage; доказуемая матрица заказа и полная поддержка PDF/CSS/обводок; сравнение normal probing, grid distance transform и точного векторного расстояния на одном и том же списке локальных ROI. Production OK не включать до прохождения отдельной приёмки.
