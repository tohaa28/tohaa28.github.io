# M3.20 — локальная проверка архивов «Согласование макета»

**18.11.2026 · Vision AI / PrintCheck Vision · экспериментальная ветка.**

## Для чего

Автообход штатных диалогов «Согласование макета» (только счётчик
сообщений >1) сохраняет отдельный **приватный** JSON с замечаниями
дизайнеров и ZIP-части с исходными байтами PDF/PSD/изображений.
Эти файлы должны оставаться на доверенном локальном компьютере.

Инструмент: tools/vision_approval_archive_audit.py — автономная проверка после
скачивания. Она не запускает браузер, не подключается к gifts.ru, не
передаёт файлы и не меняет заказ. Требуется Python 3.10+;
внешних библиотек не требуется.

## Запуск (в доверенной локальной папке)

Перечислить **все** части ZIP (пример для двух частей):

    python tools/vision_approval_archive_audit.py --evidence "C:\Private\vision-private-approval-evidence.json" "C:\Private\vision-private-approval-attachments-part-0001.zip" "C:\Private\vision-private-approval-attachments-part-0002.zip"

Скрипт проверяет:
- структуру ZIP, CRC, отсутствие шифрования/компрессии/произвольных путей;
- SHA-256 каждого оригинала относительно приватного manifest.json;
- размер, ограничение 16 МБ/файл и 24 МБ/часть, максимум 64 файла;
- номера частей подряд, без повторов, общий идентификатор заказа;
- связь «порядковая запись артикула → сообщение → вложение»;
- при --evidence: соответствие **каждого** успешно считанного файла
  приватному JSON, включая идентификатор, исходное имя, длину и SHA-256.

Для полной проверки **передавайте --evidence**: без него можно
проверить только указанные ZIP-части. Если последнюю часть забыли указать,
и JSON отсутствует, её отсутствие невозможно доказать.

Успех: JSON со статусом LOCAL_ARCHIVES_VERIFIED и
evidence_crosschecked:true. Ошибка: MANUAL_ARCHIVE_AUDIT_FAILED,
код причины и ненулевой код завершения. Стандартный вывод не содержит
номеров заказов, артикулов, исходных имён файлов, текстов обсуждения,
локальных путей или контрольных сумм.

## Что НЕ подтверждается

Совпадение контрольных сумм проверяет внутреннюю целостность архива,
но **не доказывает**, что конкретные байты действительно пришли с
gifts.ru. Manifest и вложение могут быть совместно подменены.
Проверка не устанавливает версию PDF, соответствие технологии нанесения,
физический масштаб, ROI, дефектность и результат независимой экспертизы.

Поэтому training_ready=false, production_approved=false и
использовать эти сведения для автоматического допуска макета нельзя.

Приватные ZIP/JSON никогда не загружать в публичный GitHub, Issues,
CI-логи или облачные сервисы. В репозитории хранится только код и
синтетическая проверочная выборка.

## Регрессия

    python -m unittest discover -s tests -p 'test_vision_approval_archive_audit.py' -v

Проверяются: успешная синтетическая связка, изменение байтов той же
длины при пересчитанном CRC, несовпадение артикула/вложения с JSON,
недостающая часть, подмена пути, флаги обучения, ZIP-сжатие, повтор
части и отсутствие приватных данных в stdout. Запуск включён в
PrintCheck Vision rules and dataset safety (GitHub Actions).
