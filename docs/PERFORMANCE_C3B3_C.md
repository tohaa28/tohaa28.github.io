# PrintCheck Vision — C3B.3.C: производительность анализа векторных контуров

Дата: 2026-11-16  
Область: экспериментальный CPU-модуль vision/geometry/vector-corridors.mjs  
Статус: **оптимизация подтверждена на синтетических сценариях; реальные заказные PDF не протестированы**

## Задача

Прежний измеритель перебирал каждую пару границ для проверки пересечения и поиска устойчивых параллельных участков. При N отрезках базовая стоимость двух циклов — O(N²); дополнительно каждая пробная точка проверялась по всем замкнутым контурам. Типовые многообъектные шелкографические макеты быстро приближались к лимиту 768 сегментов.

**Стратегия:** не ограничивать число соседей, не уменьшать точность геометрии, не подменять векторные проверки растром и не пропускать пограничные детали.

## Реализация

1. **Полный пространственный broad-phase.** Для каждого векторного ребра строится физический AABB. Индекс равномерных ячеек выдаёт все потенциально пересекающиеся AABB, не более 32 ячеек на ось. Запрос по второй стадии расширяется на разрешённую ширину локального коридора; каждая реальная близкая пара остаётся кандидатом. Исходный узкий геометрический предикат не меняется.
2. **Точный отсев по AABB контура.** Перед проверкой девяти точек между потенциальными границами пропускаются те контуры, вне bbox которых находится точка. Если точка могла быть на границе или внутри неё, сохраняется прежний point-in-polygon.
3. **Защита от патологических форм.** Если индекс требует чрезмерного числа ссылок, выполняется полный эталонный перебор. Никакие пары не отбрасываются по k-nearest/плотности или квоте.
4. **Эталонная проверка.** Параметр pair_index=reference позволяет сравнивать полный перебор и ускорение в одном коде; проверяются все найденные кандидаты, координаты, измеренные мм, неопределённость, исходные идентификаторы стенок и статус ошибки. Вывод о пригодности заказа остаётся заблокированным.

## Корректность и перестраховки

- Способ заполнения (evenodd), исходные точки, проверка пересечений, минимальная длина устойчивого параллельного участка, обработка концевых острых участков не изменялись.
- Ускорение не изменяет материальные пороги Gifts.ru и не включает ML.
- Несколько тестов сравнивают точные результаты spatial/reference, включая повороты, отражения, масштабирование, реальные касания, пересечения, микрозазоры и детерминированные псевдослучайные фигуры.
- Превышение бюджета индекса приводит к эталонному алгоритму, а не к частичному и ошибочно «успешному» результату.
- Нет полного доказательства минимальной толщины всего макета. Метод по-прежнему даёт локальные кандидаты; статус RESEARCH_CANDIDATES_ONLY, geometry_proven=false, print_scale_proven=false.
- Оценка времён распространяется только на эти синтетические наборы. Для кривых, тесно расположенных пересечений, технологических PDF с сотнями объектов и длинных замкнутых контуров следует выполнить отдельную производительную и функциональную проверку на закрытых реальных макетах.
