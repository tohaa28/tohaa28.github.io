# Макетная — форматирование интерфейса, 2026-10-08

## Правило №1 — статус загрузки логотипа

Фраза **«Загрузите логотип для выбранного поля.»** должна отображаться только тогда, когда реально выбрано **поле из шаблона** и открыт его режим просмотра.

Реализовано: статус `#status` при показе этого точного текста скрывается, если одновременно не выполнены условия:
- `y.template` существует;
- `y.view` открыт;
- `y.field` выбран;
- `y.active >= 0`;
- `y.placements[y.active].fieldIndex` — целочисленный индекс поля из шаблона.

Статусы другого содержания сохраняют обычную видимость. `X()` синхронизирует скрытие подсказки при переключении на «Шаблон целиком», снятии выделения или закрытии области поля, а `Q()` — при смене текста статуса.

Изменение сделано только в `tools/patch-artwork-preflight.mjs`, чтобы не нарушать воспроизводимый механизм патча собранного `assets/index-BpU9kvz8.js`. Дополнена проверка интерфейса в `tests/logo-preflight-browser.mjs`.
