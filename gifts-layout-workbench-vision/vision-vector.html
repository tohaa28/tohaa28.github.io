Анализ исходных SVG-контуров

Точные локальные измерения печатных линий и пустот по исходным кривым и векторным объектам без преобразования в пиксели. Растровый нейросетевой анализ остаётся отдельным инструментом.

Векторный макет

Поддерживаются замкнутые заполненные path, физический размер документа, viewBox, единая краска, простые групповые transforms и кривые Безье. Сложные PDF, обводки, текст, clipping, маски, RGB/spot-смеси → ручная проверка.

SVG обрабатывается только локально. JSON содержит координаты измерений, без исходных путей. Размеченный SVG содержит исходную геометрию для передачи технологу.

Не допуск к печати. Миллиметры SVG-документа не подтверждают фактический размер размещения в заказе. Нельзя считать отсутствие кандидатов доказательством годности.
