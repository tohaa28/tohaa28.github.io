# Mockup Lab

Отдельный экспериментальный модуль для построения мокапов по данным Gifts Layout Workbench («Макетная»).

## Изоляция

Mockup Lab публикуется в `/mockup-lab/` из отдельной ветки `mockup-lab-source`.
Файлы и логика `/gifts-layout-workbench/` не изменяются.

## Задача

Один раз сопоставить поле нанесения конструктора с реальной областью на фотографии товара и сохранить профиль. Затем профиль можно применять автоматически к новым макетам того же артикула/варианта/места.

Профиль `gifts-mockup-profile/v1` хранит:
- article / variant / place / method;
- идентификатор фотографии;
- прямоугольник поля в координатах конструктора;
- 4 нормализованные точки области нанесения на фотографии;
- тип поверхности;
- параметры рендера.

## Handoff из «Макетной»

Редактор читает `localStorage["gifts.mockupLab.handoff.v1"]` или импортирует JSON вручную.

Рекомендуемый payload:
```json
{
  "schema": "gifts-mockup-handoff/v1",
  "order": "7980838",
  "article": "15637",
  "variant": "",
  "place": "лицо",
  "method": "LM1",
  "photoCandidates": [
    {"name": "15637_7_200x200.jpg", "url": "https://..."}
  ],
  "photoDataUrl": "",
  "templateName": "constructor.pdf",
  "constructorPreviewDataUrl": "",
  "templateWidth": 1000,
  "templateHeight": 1000,
  "fieldRect": {"x": 320, "y": 410, "w": 180, "h": 180},
  "fieldCompositeDataUrl": ""
}
```

Для гарантированного экспорта PNG лучше передавать изображения как data URL/blob, а URL Gifts использовать как метаданные: чужой origin может блокировать чтение canvas через CORS.

## Текущая версия

Работает:
- ручное выделение поля на превью конструктора;
- 4-точечная привязка области нанесения на фотографии;
- перспективное mesh-преобразование;
- экспериментальная цилиндрическая деформация;
- opacity/blend;
- сохранение/загрузка профиля JSON;
- экспорт PNG;
- чтение будущего handoff через localStorage.

Дальше:
1. автоматическая передача данных из «Макетной»;
2. список найденных фотографий и выбор фото для каждого места;
3. библиотека профилей по article/variant/place/photo;
4. маски/occlusion и светотень;
5. автоматическое первичное совмещение конструктора и фото.
