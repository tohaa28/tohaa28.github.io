## Базовая архитектура

Макетная запускается поверх gifts.ru через `launcher.js`. Launcher создаёт полноэкранный iframe и передаёт в него `srcdoc`, внутри которого есть локальный proxy API для чтения авторизованных страниц gifts.ru. Основные запросы:

- `/api/session`
- `/api/basket`
- `/api/orders/<order>`
- PDF/preview/photo endpoints заказа

Редактор использует собранный bundle `assets/index-BpU9kvz8.js`. Критичные UI-изменения в bundle требуют cache-busting в `editor.html` и в обоих launcher-файлах.

## Основные правила проекта

- Не использовать Floot.
- Публикация через GitHub Pages.
- Не ломать уже реализованную функциональность при UI-правках.
- Перед значимыми правками сохранять rollback branch.
- При выборе артикула сначала показывать шаблон целиком.
- Поля выбираются после просмотра шаблона; автофокус на единственное поле отключён для выбора артикула.
- Одностраничный PDF не показывает навигацию страниц.
- Многостраничный PDF сохраняет навигацию.
- Названия мест нанесения и коды брать из заказа точно.
- `[print1]`, `[print2]` и т. д. соответствуют полям шаблона.
- Поля произвольной формы должны использовать реальную форму, не bounding box.
- Кнопки и интерфейс должны быть компактными, без дублирующих служебных элементов.

GitHub Pages для этого commit завершился успешно.

## Последний известный риск

Механизм даты заказа зависит от текста страницы gifts.ru. Если верстка/формулировка изменится, дата должна просто не отображаться, но запуск Макетной не должен ломаться.

После любых изменений внутри `frame.srcdoc` обязательно проверять внешний JavaScript `launcher.js` на корректность кавычек и экранирования.
