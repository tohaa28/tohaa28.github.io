### UI / Заказы

- Заголовок простого режима: `Создать макет для заказа`.
- Подсказка под корзинами:
  `Нажмите карточку заказа, чтобы перейти к созданию макетов по заказу.`

- `Добавить логотип в остальные поля` перенесено из левого фрейма в панель инструментов логотипа.
