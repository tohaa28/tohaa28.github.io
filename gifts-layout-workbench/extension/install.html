Локальный мост Макетной

Мост нужен только для того, чтобы статическая Макетная на GitHub Pages могла использовать вашу уже авторизованную сессию gifts.ru и читать корзину/заказы без backend.

Скачать ZIP с GitHub

Firefox — для тестирования

  1. Распакуйте ZIP и откройте внутри папку extension. Внутри откройте папку extension.
  2. Откройте about:debugging#/runtime/this-firefox.
  3. Нажмите Load Temporary Add-on / Загрузить временное дополнение.
  4. Выберите файл extension/manifest.json.
  5. Вернитесь в Макетную и обновите страницу.

Временное дополнение Firefox действует до перезапуска браузера. После стабилизации его можно упаковать и подписать как обычное Firefox-дополнение.

Chrome / Edge

  1. Распакуйте ZIP.
  2. Откройте страницу расширений: chrome://extensions или edge://extensions.
  3. Включите Режим разработчика.
  4. Нажмите Загрузить распакованное расширение.
  5. Выберите распакованную папку с manifest.json.
  6. Обновите страницу Макетной.

Как работает вход

Нажмите «Войти» в Макетной. Откроется настоящая страница gifts.ru/auth. Введите данные там. Макетная не получает и не хранит пароль. После успешного входа она сама обнаружит сессию и обновит корзину.

Доступ расширения

Расширение имеет доступ только к gifts.ru, files.gifts.ru и странице Макетной на tohaa28.github.io. Оно не использует внешний сервер.
