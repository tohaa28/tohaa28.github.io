Макетная gifts.ru

Версия без backend и без расширения. Редактор запускается непосредственно внутри gifts.ru, поэтому использует обычную авторизацию сайта, читает корзину и загружает PDF как same-origin запросы.

  1. Создайте в браузере закладку с именем Макетная.
  2. Вставьте в адрес закладки код запуска Макетной.
  3. Откройте gifts.ru и нажмите эту закладку.
  4. Редактор откроется поверх текущей страницы gifts.ru.
Открыть gifts.ru ↗
Макетная только читает корзину/заказы и загружает шаблоны. Статусы заказа и «Согласования макетов» не изменяются.

Код редактора и лаунчера хранится на GitHub Pages. Отдельный сервер не используется.
