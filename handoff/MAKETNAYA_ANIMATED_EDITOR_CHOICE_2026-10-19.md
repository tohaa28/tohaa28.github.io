# Макетная — анимированный выбор редактора логотипа (19.10.2026)

## Запрос
1. Убрать из видимого статуса точную строку «Из VectorCraft возвращён только нарисованный логотип с его габаритами и положением.»
2. По кнопке «Редактор логотипа» открыть короткую анимацию выбора двух движков вместо старого выпадающего меню:
   - **Чёртик** → **VectorCraft** (аналог Adobe Illustrator)
   - **Ангел** → **TraceDraw** (аналог CorelDRAW).

## Реализация
- `assets/logo-editor-choice.js` — полноэкранный полупрозрачный оверлей, две карточки с нарисованными inline SVG персонажами; отдельные CSS keyframes появления (чёртик снизу-слева; ангел сверху-справа, мягкие покачивания), без внешних ресурсов. Клик по персонажу / карточке открывает прежний host engine, без изменения исходного placement token.
- Нажатие Escape, крестик и клик по внешнему фону закрывают сцену. При повторном открытии анимация проигрывается заново. Есть поддержка `prefers-reduced-motion` и мобильная сетка.
- Скрывается **только точный** устаревший текст в `#status`, через наблюдатель за изменением текстового содержимого, после чего другие сообщения об ошибках и ходе обработки остаются видимыми.
- `editor.html` использует cache-busting `logo-editor-choice.js?v=20261019-animated-2` для обновления даже в iframe Макетной.
- `tests/logo-editor-choice-browser.mjs` обновлён для новых персонажей, анимации, маршрутизации, скрытия статуса, открытия и закрытия.
- `tests/editor-choice-animation.test.mjs` — синтаксический и статический regression-тест нового selector.
