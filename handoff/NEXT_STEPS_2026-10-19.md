# Макетная — план продолжения, тест-план и ограничения (19.10.2026)

Этот документ — *backlog*, не распоряжение менять работающую production без следующего запроса пользователя. Актуальный запуск нового чата — [START_HERE_2026-10-19.md](START_HERE_2026-10-19.md).

## Сначала, перед любым изменением
1. Получить текущие `gifts-layout-workbench-mockups-source` и `main` SHA, сравнить c ветками checkpoint. **Не слепо сбрасывать до checkpoint**, поскольку source после него содержит полезную документацию, а production содержит собранные WASM.
2. Создать новые ветки `backup-before-<название>-20261019-source` и `backup-before-<название>-20261019-production` от *текущих* HEAD; не трогать старые замороженные ссылки.
3. Проверить `mockup-profiles.json` / `method-settings.json`, исходную связку артикул ↔ поле конструктора, обе папки WASM, настройки метода нанесения и персональные черновики.
4. Согласовать объём изменений с фактическим сообщением пользователя, оставив остальные компоненты неизменными.

## Последняя интеграция (функционально проверена)
Под кнопкой «Редактор логотипа» два пункта: прежний VectorCraft и TraceDraw 0.9.4; каждый запускает отдельный iframe host, берет текущий imprint token, исходный логотип и mm field. Возврат из TraceDraw — `gwb-tracedraw-svg` с SVG + bounds из настоящего Rust; `gwbApplyEditedLogoToActiveField` проверяет совпадение текущего поля и габаритов. Кнопка переноса находится в HTML внутри TraceDraw iframe и вызывает WASM-экспорт, а не является native egui. Фактический live-тест успешен (см. run `39231640175`).

## Технические приоритеты, если пользователь попросит «продолжать TraceDraw»
### 1. Зафиксировать режим текущего поля и запретить создание других документов
Проверить все upstream команды `File > New`, `Open`, `New from Template`, `Close`, плюс tab/splash/drop/import. Для embedded режима запретить **замену** заданной страницы чужим документом и свободное создание нового, оставив импорт объектов в текущее поле. Разделять открытие документа и импорт графики. Учитывать отмену закрытия и восстановление исходного лого. Файл для patch: `tools/patch-tracedraw-upstream.py`; сам engine остается независимым upstream.

### 2. Форматы: раздельно импорт исходника и перенос обратно
Сейчас из Макетной разрешены SVG/PDF (плюс PNG/JPG преобразуются в SVG-контейнер). Подпись пункта меню `SVG/CDR` вводит в заблуждение: напрямую .cdr пока не импортируется. Либо временно уточнить надпись до `SVG/PDF`, либо реализовать CDR → TraceDraw объектами **без перехода в новый документ** через `tracedraw-cdr` и импорт в поле.
Экспортировать только нарисованную геометрию/растровые слои, но не белую страницу; проверять реальный bounding box, отрицательные координаты, масштаб мм, clip/mask, группы, поворот и профили цвета. Не растягивать из-за full-artboard viewBox и не сбрасывать место нанесения.

### 3. Тестировать реальные правки фигуры
Проверки реального WASM сейчас проверяют входящий прямоугольник, размеры поля, native Rust SVG exporter и возврат. Добавить проверку конкретной операции по объекту в TraceDraw: select, изменённый размер/цвет/узлы, undo/redo, сохранение; ошибки не должны заменять исходник. Отдельно тесты на импорт PDF, текст/кривые, clipping и отрицательные координаты, растр внутри SVG, большой файл и пустое поле.
Риск: формат CorelDRAW может включать объекты, профили и эффекты, которые TraceDraw пока экспортирует иначе. Сравнивать вектор и физическую геометрию, не только скриншот.

### 4. UX
Выбор редакторов должен появляться **под старой кнопкой**, не ломать Step 3 и работу полноэкранного редактора. Строка «Закрыть Макетную» внешнего launcher скрывается при любом открытом редакторе; закрытие без применения восстанавливает интерфейс. Должна быть одна кнопка переноса в активном редакторе и точное название **«Перенести на шаблон артикула»**. Не открывать два независимых редактора для одного поля одновременно.
Убедиться, что выбранная опция TraceDraw не заявляет неработающий прямой CDR handoff.

## Сопутствующие задачи проекта, НЕ считать закрытыми
- Личные PDF черновики должны сохраняться на сервере с идентификатором, достоверно полученным из **серверной** авторизации gifts.ru. Сейчас есть API-прототип `server/personal-layouts/index.mjs`, но реальный trusted reverse proxy и серверная проверка сессии не подключены; фактически IndexedDB. Не хранить artwork в публичном GitHub.
- PrintCheck: вектора/растр, обнаружение мелких позитивных элементов, промежутков и выворотки, охранное поле, color model, TT по виду нанесения; сохранять существующую функциональность при изменениях.
- Редактор мокапов: сохраненные на сервере привязки фото/полей, цилиндрическая поверхность с правильной разверткой, масштабом, перспективой, скрытой обратной стороной; не вводить нежелательный фон.
- VectorCraft: CMYK-сессия, исходный выбранный логотип, единицы мм, art-only SVG, запрет произвольного нового документа, сохранение версии и проверка старого стабильного пути.
- UI Макетной: пошаговый выбор артикула/места, реальные коды нанесения, заказные карточки, современная анимация без кнопки остановки, без лишних переключателей устаревшего оформления.

## Как запустить CI и реальный WASM
Основной pipeline: `.github/workflows/publish-maketnaya-mockups.yml` (precheck → publish → browser_verify), запускается изменением source. Входящие тесты: `tests/logo-editor-choice-browser.mjs`, `tests/tracedraw-integration-browser.mjs`, `tests/vectorcraft-handoff-browser.mjs`, `tests/vectorcraft-parent-close-browser.mjs`, `tests/personal-layout-library-browser.mjs`, `tests/personal-layout-server-browser.mjs`, `tests/order-motion-runtime-browser.mjs`, а также тесты PrintCheck и mockup.
- Изменение `tools/tracedraw-embedded.rs`, `tools/patch-tracedraw-upstream.py`, `.github/workflows/build-tracedraw-web.yml` запускает **Build TraceDraw WebAssembly**. Rust компилируется из точного upstream SHA `0f206489...`; WASM устанавливается в `main/gifts-layout-workbench-mockups/tracedraw/`.
- ТОЛЬКО ПОСЛЕ успешной сборки, публикации GitHub Pages запускать `.github/workflows/verify-tracedraw-live.yml` (или retry) с `tests/tracedraw-runtime-browser.mjs`. До публикации он проверяет предыдущую версию — преждевременный FAIL не равнозначен дефекту новой.
- Аналогичный отдельный `build-vectorcraft-web.yml` для VectorCraft, не запускать без изменений его Rust патчей.
- Во время любого `publish-maketnaya-mockups.yml` **сохранять оба бинарных каталога** `vectorcraft` и `tracedraw`; простой `rm -rf gifts-layout-workbench-mockups` без восстановления этих папок уничтожит работающие редакторы.
- Проверить реальную страницу gifts.ru в авторизованной сессии, а не только локальные mock и GitHub Pages.

## Защитные критерии перед публикацией
- Нет новых ошибок в существующих unit/browser тестах.
- VectorCraft по-прежнему открывает актуальное поле и возвращает logo-only SVG.
- TraceDraw импортирует тестовую фигуру, корректно возвращает bbox/мм и не заменяет соседние поля.
- Все статусы, даты и номера версий выводятся из реальных результатов.
- Source/main `mockup-profiles.json` и `method-settings.json` не перезаписаны из старых бэкапов.
- Развёрнутые персональные черновики не попадают в публичное хранилище.
- Если пользователь запросил откат, откатываются соответствующие кодовые файлы/бинарники, а не настройки всех пользователей.
