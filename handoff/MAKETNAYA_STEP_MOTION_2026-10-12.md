## Возврат без переписывания истории
В актуальном checkout рабочей ветки `gifts-layout-workbench-mockups-source` восстановить функциональное дерево из резервной ветки, создать новый commit и push. Сохранить новый дизайн в отдельной резервной ветке перед возвратом. После успешных `precheck`, `publish`, `browser_verify` и Pages проверить опубликованные файлы.

Пример после сохранения текущего HEAD:
```bash
git restore --source=backup/maketnaya-source-before-step-motion-2026-10-12 --staged --worktree .
git commit -m 'Restore stable Maketnaya before step motion interface'
git push origin gifts-layout-workbench-mockups-source
```
Новые добавленные файлы перед commit также удалить из отслеживаемого дерева, если они отсутствуют в backup (обычный `git restore` по всей корневой pathspec восстанавливает и удаления). Не использовать force-push. При работе через GitHub Git Data API создать commit с tree SHA резервного коммита и текущим HEAD как родителем, затем выполнить update_ref с expected_sha текущего HEAD.

## Архитектура
- `assets/workbench-flow.js`: отдельный слой представления. Перемещаются реальные элементы, не создаются копии контролов и отдельное состояние макета. Пошаговая навигация не вызывает загрузку файла или перерисовку редактора.
- `assets/workbench-flow.css`: штатная палитра gifts, карточки и панели, явные шаги, основные инструменты, правая панель настроек (на телефоне в обычном потоке).
- Оба файла подключены к editor.html и mockup.html; build-launcher rebases ссылки для srcdoc.
- Состояние берётся из `gwbGetEditorReadiness`; доступность переходов зависит от реально загруженного шаблона, поля и логотипа. Штатные проверки и запрет экспорта с неподтверждёнными ошибками не заменяются.
- `window.gwbFlow`: навигация/раскрытие настроек для браузерных проверок; не меняет данные редактора.
- WAAPI-переходы отменяются при следующем действии; reduced-motion отключает внутреннее движение.
- Стартовая заставка `tools/launcher-motion.mjs` не менялась.
- PrintCheck, геометрия и алгоритмы мокапов, серверные профили не менялись.
