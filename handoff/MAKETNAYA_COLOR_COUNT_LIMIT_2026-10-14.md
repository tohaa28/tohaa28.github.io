# Макетная — контроль количества цветов нанесения (14.10.2026)

## Запрос
Пользователь требует настраивать допустимое количество цветов по каждому виду нанесения — 1, 2, 3 и более — и проверять исходный макет на соответствие, включая загруженные SVG, PDF и растровые логотипы.

## Реализация
- `assets/method-admin.mjs`: прежний параметр `maxColors` выделен из общей сетки чисел в отдельную понятную настройку «Количество цветов нанесения» с вариантами «По исходным требованиям» и 1–32 цвета. Селектор выводит унаследованный предел, если тот задан в базе вида нанесения. Внесённое значение сохраняется как `methods[CODE].values.maxColors` в прежнем формате JSON `version:1`, совместимом со всеми сохранёнными настройками, импортом и экспортом. Лимиты независимы для каждого нанесения. Отключение группы «Цветность и цветовая модель» отключает и эту проверку.
- `assets/logo-color.mjs`: `colorFindings` теперь проверяет максимум цветов отдельно от политики цветности (поэтому лимит можно задавать также для ранее чёрно-белых режимов). Для чистого SVG подсчитываются реально встречающиеся цвета заливок/обводок; векторный явно заданный белый тоже может быть отдельной краской. Если подтверждённый счёт выше максимума — диагностика `colors:bad` и запрет выгрузки, в пределах — `colors:ok`.
- Для растра используются стабильные однородные внутренние участки, а не все уникальные пиксели JPEG/PNG и не сглаживание по контуру. Добавлена осторожная оценка `provenInkCount` по действительно различимым цветовым группам; если нижняя граница превышает лимит — ошибка. Если точное количество печатных красок не подтвердить, статус `manual` с объяснением необходимости проверить цветоделения. Оттенки одной краски не приравниваются к отдельным цветам.
- PDF.js преобразует исходные spot/CMYK/ICC цвета для просмотра. Поэтому по одному лишь визуальному RGB-превью PDF результат не подтверждается автоматически, а требует контроля исходных цветоделений. Существующий анализ цветов в `logo-preflight.mjs` продолжает работать, но теперь использует `logo-color.mjs?v=20261014-colors-1`.
- `tools/patch-artwork-preflight.mjs`: версия подгружаемых модулей обновлена до `method-admin.mjs?v=20261014-colors-1`, `logo-preflight.mjs?v=20261014-colors-1`, зафиксирован SHA-256 интегрированной сборки `65590b0ebf265d749ed74e9a354d50aa88a2d4dc5c112d825ece05204a20718b`.

## Действия оператора
Открыть нужное поле в Макетной → Alt+N → войти в «Настройки нанесений» (текущий метод подставляется автоматически) → параметр «Количество цветов нанесения» → выбрать «1 цвет», «2 цвета», «3 цвета» и т.д. → Сохранить. Настройка применится при проверке текущего и следующих загруженных макетов этой технологии.

## Важно
Реальное число физических красок не всегда равно числу видимых RGB-оттенков: фотография, CMYK, растрирование, полупрозрачность, белая подложка, градиенты и полноцветная печать могут требовать изучения оригинала и цветоделений. Автоматический «ОК» для чистого вектора относится к выявленным заливкам/обводкам, а не к независимой сертификации всей технологической схемы.
