# Хронология и карта решений «Макетной» на 17.10.2026

Документ описывает принятую архитектуру, последовательность изменений и ключевые решения. Для актуальных SHA и безопасного возобновления работы считать основным `START_HERE_2026-10-17.md`. Более ранние исторические документы не удалять.

## 14–30 сентября — исходная Макетная, связь заказа с конструктором, начало PrintCheck

- Идея: технический дизайнер получает номер заказа gifts.ru, точные артикулы, выбранный тип и место печати; скачивает клиентские файлы и привязанные к артикулу конструкторы из «Макеты для заказа». Не использовать окно согласования и не создавать вымышленные поля.
- На базе реального конструктора выделяются цветные поля [print1], [print2] и поля свободной формы. Для произвольной формы нужен реальный контур, не bounding box; служебная таблица и зелёный блок вне зоны нанесения.
- Web-редактор работает без Chrome extension. Заказы из корзины группируются, шаги: заказ → артикул → место нанесения → выбранный шаблон → логотип → скачать макет. Должны сохраняться несколько мест/логотипов и сложные многостраничные макеты.
- PrintCheck: проверка по техтребованиям gifts.ru, допустимая модель цвета/количество красок, реальные толщины позитивных линий, перемычек и негативных пробелов, охранное поле, шрифты, прозрачности/градиенты, размеры.

## 1–8 октября — работа с малой графикой, производительностью, отдельными версиями

- На практике дизайнер накладывает круг минимального допустимого диаметра на элементы и просветы; требование — определять позитивные/негативные дефекты даже в растровых логотипах, исключать пересечения разных цветов и нормальные стыки букв.
- Прежние алгоритмы давали ложные дефекты на краях и пропускали тонкие линии; улучшения coverage/SWT и независимые изменения v24/v25 в документах `PRINTCHECK_HANDOFF_2026-10-08-v25.md`. Это отдельная незавершённая по реальным пользовательским файлам область — не объявлять стопроцентное соответствие.
- UX PrintCheck: статус «поиск мелких элементов…», короткий/подробный список дефектов, реальные размеры выбранного поля, а не всего шаблона; быстрый тест без заказа, выбор статьи и вида печати.

## 16 октября — интеграция редактируемых векторов и VectorCraft

- Первая версия собственного `Редактора логотипа`: открытие уже размещённого artwork, редактирование SVG-объектов и контуров, узлы/Безье, группы, текст/растр, экспорт. Этот редактор сохранён как «Открыть прежний редактор».
- Обсуждалась возможность использовать https://github.com/storytold/vectorcraft, и реализована именно **оригинальная браузерная сборка Rust/WebAssembly** на зафиксированном upstream commit `8bc65329286dc1b84aa392997bb205613c3e96cb`, а не замена на имитацию.
- Протокол: JS-host в `assets/vectorcraft-integration.js` берёт `File` из выбранного поля, передаёт байты через защищённый `postMessage`; внутри Rust I/O работает `tools/vectorcraft-bridge.rs`; по `Применить в Макетной` получает SVG и возвращает его только в исходный placement через `gwbApplyEditedLogoToActiveField`.
- Размер поля передаётся в мм и задаёт монтажную область VectorCraft; исходные x/y/w/h/rotation переносятся в редактируемые векторные трансформации. Возврат ТОЛЬКО по фактическому `art_bounds`, отдельно `logoBoundsMm`, без рамки рабочего листа. Пример теста: поле 120×80 мм, объект 40×18 мм со смещением 12×8 мм.
- Встроенный VectorCraft ограничен **одним** документом. New/Open/Recent/Home/Close и повторная передача файла заблокированы на уровнях UI/Rust, но `File → Place` и рисование сохранены. Обычная автономная редакция VectorCraft не затронута.
- По прямому запросу пользователя сохранена двухветочная контрольная точка для версии «art-only»: `checkpoint-maketnaya-vectorcraft-art-only-20261016-source` / `checkpoint-maketnaya-vectorcraft-art-only-20261016-production`.
- Основные документы этапов: `handoff/MAKETNAYA_LOGO_EDITOR_PHASE2_2026-10-16.md`, `handoff/MAKETNAYA_IMPORTED_VECTORS_2026-10-16.md`, `handoff/MAKETNAYA_VECTORCRAFT_WASM_2026-10-16.md`, `handoff/MAKETNAYA_VECTORCRAFT_FIELD_MM_2026-10-16.md`, `handoff/MAKETNAYA_VECTORCRAFT_ART_BOUNDS_2026-10-16.md`, `handoff/MAKETNAYA_VECTORCRAFT_SINGLE_FIELD_2026-10-16.md`.
