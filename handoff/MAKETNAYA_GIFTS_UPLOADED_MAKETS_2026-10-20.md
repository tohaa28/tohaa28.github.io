## Реализовано
1. `direct-mode.js`: `extractUploadedMakets(html,order,orderInternalId)` собирает только `a[data-maket="true"]` для `gifts.ru/cart/act/mda`, фильтрует по внутреннему ID заказа, поддерживает HTML модального окна и `<template shadowrootmode="open">` на сохранённой странице, сохраняет оригинальные имена и ID. Проверка в ходе стандартного чтения / обновления корзины; данные экспонируются через `GET /api/orders/:number` в `uploadedMakets`.
2. Добавлен маршрут `GET /api/orders/:number/uploaded-makets/:uploadId.pdf`. При каждом запросе заново проверяются авторизация, текущий заказ и whitelist file ID из gifts.ru. Скачивание исключительно с `gifts.ru` и `files.gifts.ru`, без доступа к произвольным URL; приём PDF с `%PDF-` до 40 МБ; никакой отправки исходника.
3. `assets/order-uploaded-makets.js`: после обновления корзины в карточке заказа отображается число загруженных файлов. При открытии заказа список PDF виден отдельным блоком с оригинальными именами и кнопкой **«Открыть для редактирования»**.
4. Импорт только после явного выбора поля в конструкторе. Загруженный PDF преобразуется в `File` и передаётся через существующее событие `#artwork.change`, без отдельного движка — с исходными PrintCheck, PDF/CMYK, геометрией, Undo/Redo. В gifts.ru оригиналы не изменяются. Несовместимые форматы не маскируются под PDF.
5. `editor.html`, `tools/stamp-component-versions.mjs`, тесты и publish workflow обновлены.
6. `tests/order-uploaded-makets-browser.mjs` содержит браузерный сценарий с двумя настоящими по форме ссылками из заказа 8006776, двух исходных имён, запретом доступа к чужому ID, бейджем и загрузкой в выбранное поле. Не содержит личных данных и временных ключей исходной HTML-страницы.
