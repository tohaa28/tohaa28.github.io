# Макетная × VectorCraft — возврат только видимого логотипа (16.10.2026)

## Назначение
Векторный редактор открывается на монтажной области **реального размера поля нанесения** (в мм). При применении из VectorCraft экспортируются **только видимые объекты рисунка**, а не пустая страница. В Макетную возвращается подрезанный SVG с размерами `w × h` в миллиметрах и независимыми координатами `x, y` относительно исходного поля; сохраняется привязка к исходному артикулу, странице и полю.

## Компоненты
1. `tools/vectorcraft-bridge.rs`: читает `doc.art_bounds()` — нативные визуальные границы геометрии (с учётом трасформированных путей и обводок); отказывается экспортировать пустой рисунок; сверяет размер монтажной области с исходным полем; вызывает нативный `fileio::encode_with_warnings(doc,"svg",{images:"embed",useArtboards:false})` для SVG с реальным bounding-box вместо artboard; с `gwb-vectorcraft-svg` отправляет `logoBoundsMm:{x,y,w,h}` через postMessage.
2. `tools/patch-vectorcraft-upstream.py`: вызывает обновлённую Rust-функцию экспорта с исходным `bridge_field_mm` из выбранного нанесения. Исходники VectorCraft берутся из закреплённого коммита upstream. Без нового Rust/WASM изменения не функционируют; старый движок **fail closed** в родителе.
3. `assets/vectorcraft-field.js`: `normalizeExport(raw,fieldSizeMm,logoBoundsMm)` проверяет реальный размер SVG (pt → mm) против серверного поля `logoBoundsMm`, ставит ширину/высоту SVG строго по собственному рисунку в мм. Не допускает тихого растягивания полного рабочего листа.
4. `assets/vectorcraft-integration.js`: принимает `logoBoundsMm` от настоящего VectorCraft, передаёт исходному bridge `{artworkBoundsMm,fieldSizeMm}` вместе с настоящим File SVG. При отсутствии метаданных или некорректных размерах остаётся исходный логотип.
5. `tools/patch-logo-editor-bridge.mjs`: после синтаксического/PrintCheck импорта `Qe` и верификации токена активного поля вычисляет `placement={x:field.x+bounds.x,y:field.y+bounds.y,w:bounds.w,h:bounds.h,rotation:0,clipToField:previous.clipToField}`. Векторные повороты и искажения уже находятся в SVG, двойная трансформация запрещена.
6. `editor.html` обновил cache buster скриптов `vectorcraft-field.js` и `vectorcraft-integration.js` на `?v=20261016-art-1`.

## Ограничения и защита
- Редактор на фрейме поле-работает как раньше; редактируются все импортированные SVG-группы, не растрируются.
- Реальные bounds включают *видимую графику*; залитые фоны, если они нарисованы как обычные фигуры, закономерно считаются частью логотипа. Никакого удаления логотипных деталей.
- Строка импорта файлов и серверные данные не изменяются. Корректный адрес и токен исходного поля обязателен для возврата.
- Если у созданного документа нет графики, пустой логотип не отправляется и исходный файл остаётся на месте.
