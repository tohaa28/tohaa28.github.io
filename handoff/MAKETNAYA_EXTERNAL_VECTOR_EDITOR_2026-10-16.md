# Макетная — редактор векторного логотипа в CorelDRAW / Illustrator (16 октября 2026)

## Задача и границы
Добавить рядом с инструментами размещения логотипа команду «Редактировать вектор». Пользователь редактирует исходный SVG/PDF или PDF-совместимый AI во внешнем CorelDRAW/Adobe Illustrator и получает результат обратно в **то же выбранное поле Макетной**, сохраняя координаты, размер в пределах прежних габаритов, угол, режим обрезки и другие поля заказа. Редактирование в Corel/Illustrator — **локальная Windows-функция**: браузер не имеет права самостоятельно запускать произвольные программы или читать изменённые файлы без помощи локальной программы.

## Реализация
- `editor.html`: контекстная кнопка «Редактировать вектор» рядом с «Добавить / Заменить логотип»; показывается только при выбранном векторном исходнике SVG, PDF, PDF-совместимом AI.
- `assets/vector-external-editor.mjs`: окно выбора CorelDRAW/Illustrator/программы по умолчанию, «Открыть в редакторе», «Скачать оригинал», «Вернуть изменённый файл», ссылки на помощник Windows. Без помощника работает ручной цикл выгрузки исходника и возвращения SVG/PDF. При доступном помощнике передаёт копию файла только в локальную программу по `http://127.0.0.1:14762`, запускает выбранный редактор и отслеживает сохранение SVG/PDF. После первого возврата следующие сохранения также принимаются. Если выбор активного поля/логотипа изменён, возврат отменяется, чтобы не перезаписать соседний логотип.
- `tools/gwb-vector-bridge.py`: локальный Windows HTTP-помощник на Python 3 без сторонних пакетов: слушает только loopback `127.0.0.1:14762`, использует Origin allowlist и случайный nonce, ограничивает размер файла 40 МБ, проверяет расширение и идентификаторы сессий. Запускает CorelDRAW/Illustrator как отдельный процесс, не исполняет команды из веб-запроса. Статус изменённого файла выдаёт только после стабилизации его размера и времени изменения. Файлы редактирования хранятся локально в `%LOCALAPPDATA%\\GWBVectorBridge`. Промежуточная копия исходника не заменяет оригинал заказа.
- `tools/start-vector-bridge.cmd`: старт Windows-помощника через установленный Python 3; оба файла нужно сохранить в одну папку и запустить CMD один раз на этом компьютере. Редактор и помощник должны оставаться запущенными, пока идёт работа. После остановки помощника доступен ручной возврат файла.
- `tools/patch-artwork-preflight.mjs`: добавляет импорт модуля, связывает его с уже выбранным размещением в существующей скомпилированной Макетной и вызывает штатный `Qe(file,'art')`. Новый файл проходит прежний PrintCheck/preflight. Для изменения пропорций артборда применяется `restorePlacement`: изображение пропорционально вписывается внутрь старого ограничивающего прямоугольника без растягивания. Сохраняются `rotation`, `clipToField`, координаты центра, поле, страница и другие логотипы. Отладочные обходы запретов экспортирования отсутствуют.
- `.github/workflows/publish-maketnaya-mockups.yml`: публикует оба файла Windows-помощника в `gifts-layout-workbench-mockups/tools/`. В CI исполняется `python3 -m py_compile` и тест локального HTTP-моста.
- `tests/vector-external-editor.test.mjs`: проверяет допустимые исходники, неизменность прямоугольника для прежних пропорций, сохранение поворота/обрезки и пропорциональный fit нового артборда.
- `tests/vector-external-browser.mjs`: проверяет ручной возврат в тот же print field, отсутствие изменений других полей, режим, угол, обрезку и автоматический возврат из имитированного локального помощника после изменения источника.
- `tests/test_vector_bridge.py`: проверяет изоляцию localhost API, недоверенные origin, безопасный приём SVG и обнаружение завершённого сохранения.
- `.github/workflows/test-direct-workbench.yml`: включён браузерный smoke нового инструмента вместе с ранее существующими проверками заказов и мокапов.

## Порядок работы Windows
1. Обновить открытую Макетную, выбрать артикул, место и векторный логотип.
2. Нажать «Редактировать вектор».
3. Для автоматической работы один раз скачать **оба** файла из нижней части диалога и сохранить рядом, иметь установленный Python 3 и выполнить `start-vector-bridge.cmd`. Выбрать CorelDRAW или Adobe Illustrator, нажать «Открыть в редакторе».
4. Сохранить редактируемый SVG/PDF (Ctrl+S). Макетная обновит оригинал в том же поле, запустит preflight и обновит диагностику. При сохранении в **другом формате или новом имени** требуется загрузить экспортированный SVG/PDF вручную.
5. Если помощника нет, нажать «Скачать оригинал», редактировать локально, затем «Вернуть изменённый файл». Этот способ не требует Python и доступен всем пользователям.

## Ограничения, требующие реального Windows-пилота
CI подтвердил интерфейс, цикл автоматического возврата с имитацией API и реальное HTTP-чтение/запись локального Python-сервера на Linux. Запуск реального CorelDRAW/Illustrator на Windows, конкретные версии приложений, обработка Save As и поведение Chrome Private Network Access **не проверялись на компьютере пользователя**. Нужно провести пилот с установленной программой и разрешениями Windows. Нативные файлы CDR и EPS прежняя Макетная непосредственно не импортирует: необходим SVG, PDF либо PDF-совместимый AI. Если редактор сохраняет новый CDR/AI без PDF-совместимости, следует экспортировать SVG или PDF и использовать ручной возврат.
