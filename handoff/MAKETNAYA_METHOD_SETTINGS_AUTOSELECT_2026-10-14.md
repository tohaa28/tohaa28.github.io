# Макетная — автовыбор текущего нанесения в настройках (2026-10-14)

## Запрос
При Alt+N → вход в «Настройки нанесений» автоматически открывать настройки **текущего вида нанесения** выбранного артикула/поля. Для заказов с несколькими типами печати приоритет — у активного места нанесения, не у первого типа статьи/заказа.

## Реализация
- `assets/method-admin.mjs`: `initialMethodCode(method)` определяет точный код через `resolveMethod` (не по частичному совпадению). При открытии модального окна Alt+N запоминает текущий код: сначала берёт уже проверенное `gwbLogoPreflight` для `orderFieldChoice.value`, при отсутствии отчёта — подпись выбранного места; после этого проверяет способ из переданного `getCurrentMethod`. После авторизации `#adminMethod` и вся форма показывают нужную технологию. При неизвестном или неоднозначном коде работает безопасный вариант выбора вручную с объясняющим сообщением.
- `tools/patch-artwork-preflight.mjs`: передаёт callback `getCurrentMethod` в `installMethodAdmin` из основного редактора. Callback сопоставляет активное поле `#orderFieldChoice` с `y.template.fieldOptions` и `oo(index)` (связь места нанесения из заказа); если поле не выбрано, использует вид нанесения выбранного артикула/ввод `#method`. Метод не берётся из чужого поля. Импорт обновлён до `method-admin.mjs?v=20261014-current-2`, чтобы избежать старого кэша.
- Текущие настройки и управление ими сохраняют всю существующую логику: ручной выбор другого метода, черновик/отмена, импорт/экспорт, настройки типа вектор/растр.
- Контрольный SHA-256 сборки `tools/patch-artwork-preflight.mjs` обновлён: `d258b26dd87033e6b584d3bc6ecb6203dd1701808fc875383d39ca4d75c51607`.
