# Макетная — анимация шапки, CMYK VectorCraft и личная библиотека макетов
Дата: 2026-10-17. **Последняя подтверждённая функциональная версия**.

## Исходная задача
1. Исправить неработающую анимацию верхней строки.
2. Создавать/открывать редактируемые документы внутри интегрированного VectorCraft в цветовой модели CMYK.
3. Сохранять несколько результатов размещения логотипов для конкретного артикула и пользователя и позволять вручную возвращать старые версии; **не считать их макетами текущего заказа по умолчанию**.

## Исправления
### Анимация `editor.html`
У `gwbOmFly` карточки были невидимыми 69% цикла, поэтому верхняя строка выглядела сломанной и неподвижной. Теперь предусмотрены четыре распределённых пролёта по одному 18-секундному циклу, с сохранением исходных 8 поз, 4 сообщений, CSS crossfade, мобильных breakpoint и `prefers-reduced-motion`. Старый тест требовал 69% невидимости и обновлён в `tests/order-motion-banner.test.mjs`. Новый тест `tests/personal-layout-library.test.mjs` проверяет фазы.

### CMYK-документ без потери редактируемости
- В `tools/vectorcraft-bridge.rs`, в `gwb_apply_field_size`, **только для embedded Maketnaya bridge**, устанавливается `std::sync::Arc::make_mut(&mut doc.doc).color_mode=vectorcraft_doc::ColorMode::Cmyk`.
- `tools/patch-vectorcraft-upstream.py` добавляет в pinned `vectorcraft-web` manifest зависимость `vectorcraft-doc = { workspace = true }`.
- Исходные векторные элементы, art-only SVG, миллиметры, выбранное поле и I/O guards не изменены. Это реальный рабочий CMYK режим редактора, **но SVG экспорт может сохранять RGB-совместимые атрибуты**. Не обещать готовые CMYK печатные PDF или корректные ICC separations без отдельного соответствующего модуля.

### Личные сохранённые варианты
- `tools/patch-logo-editor-bridge.mjs`: не меняя первоначальную проверенную основу compiled bundle, добавляет APIs `gwbCurrentLibraryArticle`, `gwbCapturePersonalLayout` и `gwbRestorePersonalLayout` в исходный локальный state редактора. Snapshot сохраняет исходные байты всех нанесений, `fieldIndex`, page, ширину/высоту, относительные X/Y, rotation и clip. Restore строго проверяет текущий артикул, количество и геометрию конструктора, дублирующиеся/отсутствующие поля, размер; парсит все файлы через Qe до атомарной замены `y.placements`; затем выбирает первое поле через штатный `zn(0)`.
- `assets/personal-layout-library.js`: новый интерфейс внутри `#orderFieldChoiceBox`, показ после выбора артикула, отдельные **Мои сохранённые макеты**, ввод локального имени профиля, ручное `Сохранить вариант`, список с датой и числом полей, `Восстановить` с подтверждением, `Удалить`, экспорт JSON-копии и импорт JSON-копии. Хранение в IndexedDB данного устройства; scope = локальный профиль + номер артикула. ID randomUUID, статус `personal-draft`, `orderId:null`; **ни одна библиотечная запись не записывается в текущий заказ автоматически**.
- Не использовать GitHub Pages или публичный git-репозиторий для сохранения приватных логотипов клиентов. Реальная авторизованная серверная синхронизация **НЕ реализована**: локальное имя профиля — не подтверждённая gifts.ru identity, а браузерная библиотека недоступна другим устройствам без ручного JSON экспорта и импорта. Для безопасного серверного продолжения потребуются проверка пользователя, разграничение доступа, приватное object storage и API. Нельзя выдавать локальную библиотеку за централизованную.
- В `editor.html` подключён новый скрипт `./assets/personal-layout-library.js?v=20261017-1`.
