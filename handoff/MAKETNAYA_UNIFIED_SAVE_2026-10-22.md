# Единое сохранение макета — 22.10.2026

Одна кнопка «Сохранить макет в заказ на gifts.ru» в простом и расширенном режимах.
Для нового макета запрашивается имя; для открытого предлагается его текущее имя.
Перед записью список файлов заказа читается заново из gifts.ru без обоих кэшей.
При совпадении исходного имени без учёта регистра диалог предлагает «Перезаписать»,
«Другое имя», «Отмена». Новое имя проверяется повторно; Escape отменяет действие.
При нескольких совпадениях либо отсутствии права удаления доступно другое имя.
Ошибка чтения списка блокирует запись. Повторный клик блокируется на весь сценарий.
Изменение заказа или артикула до завершения подготовки PDF блокирует отправку.
Для нового файла адаптер повторно проверяет уникальность перед загрузкой; при новом
совпадении предлагает повторить сохранение. Полной атомарности внешнего API нет.
Замена сохраняет существующий протокол: загрузка и проверка нового вложения до
удаления строго выбранного ID; при отказе удаления остаются обе версии с сообщением.

Проверено локально: 204 unit tests PASS; order-uploaded-makets-browser PASS.
Браузер проверяет обе панели, отсутствие Save As, коллизию со свежим серверным
именем, отмену, повторное переименование занятого имени, ошибку чтения, запрет
дублирующего POST, создание, перезапись и частичный отказ удаления. Реальные
сетевые ответы gifts.ru моделируются, авторизованный заказ пользователя не менялся.
Снимок диалога просмотрен. Сборка launcher и проверка синтаксиса успешны.
PrintCheck, оба движка и пользовательские реестры не менялись.
