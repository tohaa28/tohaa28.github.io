## Функциональные изменения (продолжение)
1. `assets/personal-layout-library.js`: при явном сохранении варианта берётся миниатюра текущего макета. Фотография страницы конструктора и слой логотипа объединяются на клиенте в маленький JPEG. Невозможность создать thumbnail (canvas security/taint) **не блокирует** сохранение оригиналов. Миниатюры показаны в списке рядом с названием, датой, числом полей. Сохраняются только в локальном IndexedDB, также включаются в явный JSON экспорт/импорт.
2. В интерфейсе явно написано, что профиль — **локальный ярлык**, НЕ аутентификация gifts.ru и не защита от другого человека, пользующегося тем же браузерным профилем. Использовать приватный браузерный профиль для конфиденциальных клиентских файлов. Для переноса на другое устройство пользователь экспортирует личный вариант в JSON и импортирует его. Никаких удалённых uploads.
3. `tools/patch-logo-editor-bridge.mjs`: до создания локального snapshot проверяется уникальность `fieldIndex`; одинаковое поле дважды не записывается как невосстановимая библиотечная запись. При восстановлении остаются проверки артикула, списка и размеров полей, объёма файлов и атомарная замена всех размещений лишь после парсинга `Qe`.
4. `tests/personal-layout-library-browser.mjs`: реальный Chromium теперь проверяет thumbnails, экспорт JSON, импорт JSON, сохранение в IndexedDB **после перезагрузки браузера**, отсутствие автоподстановки как после сохранения, так и после импорта и перезагрузки, а также разделение профилей и артикулов.
5. `tests/vectorcraft-parent-close-browser.mjs`: исправлен нестабильный старый тест — ожидать доставки сообщения `postMessage` до сравнения массива. Сам код «Закрыть Макетную» не менялся.
6. `tools/patch-vectorcraft-upstream.py`: после открытия текущего VectorCraft документа отправлять `gwb-vectorcraft-opened` только если **активный `doc.color_mode` равен `ColorMode::Cmyk`**, с `message:"CMYK"`; иначе ошибка. `tests/vectorcraft-runtime-browser.mjs` считывает и проверяет реальное значение из опубликованного Rust/WASM. Старые ложные успешные проверки по одному UI исключены.
7. Версия в исходном `editor.html`: `r20261017-pl2`; CI может заменить её на SHA публикации. URL `vectorcraft/index.html?v=20261017-cmyk-verified-1`, подключение `vectorcraft-integration.js?v=20261017-cmyk-verified-1` и `personal-layout-library.js?v=20261017-2`, чтобы не получить устаревший браузерный кэш.

## Архитектура и ограничения
- **Персональные варианты являются локальными черновиками** с `personal-draft`, `orderId:null`. Их нельзя привязывать к текущему заказу автоматически. Не изменять каталог заказов, алгоритм PrintCheck и экспорт VectorCraft по этому запросу.
- Приложение на GitHub Pages — статическое, публичный Git НЕ подходит для приватных макетов клиентов. Имеется Vercel проект со схожим именем, но его доступ на чтение подробностей возвращает **403 scope not authorized**; безопасного приватного сервера с надёжной аутентификацией пользователя в этом релизе нет. Нельзя выдавать локальный профиль за подтверждённую identity или заявлять синхронизацию между устройствами.
- Для будущей серверной библиотеки: реальная пользовательская auth, серверная проверка прав, private blob storage, versioned API, запрет произвольного доступа по имени профиля, согласованная политика хранения/удаления, шифрование при хранении. Не сохранять исходные макеты в публичных GitHub registry.
