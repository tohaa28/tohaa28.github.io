## Technical implementation
- assets/mockup-cylinder.mjs: cylinder3DArtworkSurfacePoint now uses the same cylinder3DSurfacePoint as the green 3D body guide. This restores genuine depth-dependent axial deformation following topArc and bottomArc. No additional axial compensation that flattens the printed image.
- cylinder3DProjectLocalQuadPoint projects points of the local development quad through a homography and the shared curved cylinder function. Both the artwork triangle mesh and curved blue guide use this projection.
- mockup.html: existing blue quad/handles remain the **flat development** (blue dashed); a **solid curved blue contour** draws the actual physically distorted print boundary using the identical transformation as the artwork. Hidden rear side is not connected across the visible image.
- The full fieldCompositeDataUrl is projected as-is, with fitArtwork=false. Individual uploaded standalone logos may still use their existing aspect-preserving fit in the field.
- 3D remains subject to cylinder axis, curvature, rim arcs, photo perspective and back-face clipping; visible print and downloaded PNG use the same drawing function.
- Module cache version v=20261014-4; the source UI build string is r20261014-4. Published UI build string is generated by publish workflow.
