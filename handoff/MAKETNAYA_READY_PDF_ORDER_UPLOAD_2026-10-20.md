# Макетная — экспорт и загрузка готовых PDF в заказ (20.10.2026)

## Запрос
«Кнопку Открыть для редактирования — показывать только в режиме редактирования поля. Готовые макеты можно либо скачивать либо загружать в заказ».

## Реализовано
- Существующие прикреплённые PDF остаются в списке заказа; каждый можно скачать через контролируемый GET `/api/orders/:order/uploaded-makets/:id.pdf`.
- **Открыть для редактирования** рендерится только при состоянии выбранного реального поля (`y.view`, `y.field`, `y.active`, нативный scope), при открытой панели инструментов поля и активном виде поля (`#zoomPage`). При возврате на полный шаблон кнопка немедленно исчезает.
- Для Step 4 и расширенной панели экспорта добавлена кнопка **«Загрузить готовый PDF в заказ»** рядом с существующими элементами скачивания. Пользователь подтверждает операцию.
- Подготовка PDF использует тот же экспортёр `Qn() -> hn(...,PDFLib,Jn)`, что и обычное скачивание: те же поля, PDF-вектор/CMYK, геометрия, проверки технических требований и `confirmErrors`. Загрузка не должна выдавать отдельную неверную версию PDF.
- Доработан `tools/patch-order-uploaded-makets.mjs`: экспорт `window.gwbReadyPdfNative.snapshot/make`, запрет подмены заказа/артикула или страницы после начала сборки, лимит 40 МБ, обязательная PDF-структура. Нативный импорт клиентских PDF дополнительно требует `y.view`.
- `direct-mode.js`: новый `POST /api/orders/:number/uploaded-makets`. Каждый запрос перечитывает настоящий авторизованный заказ; официальный `form#j_upload_area` извлекается из order HTML / makets_popup (включая declarative shadow template) и сверяется по `oid`, `order`, `type=10`, `folder`, `media_file[]`. Серверная команда `POST /ajax/gifts/order?action=upload_makets` отправляет реальный multipart FormData в gifts.ru, не затрагивая прежних файлов и не обращаясь к «Согласованию макетов».
- Успех загрузки подтверждается не одним HTTP 200, а обнаружением **нового** upload ID с точным оригинальным именем PDF при повторном чтении заказа (до 3 чтений с коротким интервалом). Если подтверждения нет, выводится предостережение проверить заказ перед повторной отправкой. Кэш заказа очищается.
- После подтверждения обновляется список PDF и счётчик вложений в корзине.

## Обязательная живая проверка
Открыть gifts.ru в браузере с авторизацией пользователя, запустить закладку, выбрать доступный заказ, сформировать PDF и нажать «Загрузить готовый PDF в заказ». Убедиться, что gifts.ru принимает именно этот файл и показывает его в «Макеты для заказа» → «Загрузка макетов». Не тестировать загрузку записью в реальный заказ без разрешения. Проверка реальной авторизованной сессии не заменяется Playwright-моками.
