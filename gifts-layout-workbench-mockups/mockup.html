Инструменты включаются автоматически только после подготовки нужных данных.

1. Данные заказа

Формат передачи

Во встроенном режиме данные передаются напрямую из «Макетной»: заказ, артикул, фотография, найденные поля конструктора и текущее нанесение. localStorage оставлен только как резервный способ импорта.

2. Найденные данные

1. Фотографии артикула0
Пока нет фотографий подходящего размера
2. Поле шаблона для выбранного фото0
Пока нет полей из конструктора

Выберите любую фотографию артикула, затем поле шаблона. Для каждой пары можно отдельно сохранить, изменить или удалить разметку.

Каждая фотография артикула выбирается независимо. Одно фото можно привязать к одному или нескольким полям, а одно поле — к нескольким фотографиям.

3. Привязка

Нажмите кнопку и протяните рамку по полю нанесения на конструкторе. Если handoff уже содержит геометрию поля, шаг выполняется автоматически.

Зелёный 3D-каркас ставится по видимому корпусу: четыре угла задают боковые касательные, оранжевые точки — кривизну верхней кромки и дна. Синяя рамка — развёртка нанесения и может уходить в серые зоны за пределами фото.
