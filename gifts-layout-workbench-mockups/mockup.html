1. Данные заказа

Формат передачи

Во встроенном режиме данные передаются напрямую из «Макетной»: заказ, артикул, фотография, найденные поля конструктора и текущее нанесение. localStorage оставлен только как резервный способ импорта.

2. Найденные данные

1. Поле для разметки0

Сначала выберите поле шаблона. Затем выберите фотографию именно для этого поля.

2. Фотография для выбранного поля0
Пока нет фотографий из заказа

Каждое поле хранит собственную привязку к фотографии. Одно поле может иметь несколько размеченных фотографий — тогда для него будут создаваться несколько мокапов.

3. Привязка

Нажмите кнопку и протяните рамку по полю нанесения на конструкторе. Если handoff уже содержит геометрию поля, шаг выполняется автоматически.
