# Vision Check LAN — локальное расширение Chrome (C3B.3.R)

**Назначение:** штатный Chrome Manifest V3 механизм для чтения карточек заказов
с \`testgifts.local\` из таблицы на \`psk.testgifts.local\` в рамках
авторизованного браузера, когда обычная закладка не может прочитать
междоменный HTTP-ответ из-за CORS. Не меняет серверную политику безопасности.

**Внимание:** этот вариант использует специальные разрешения расширения Chrome.
Устанавливайте его только для вашей тестовой локальной сети. Убедитесь,
что расширение запрашивает только два хоста:
\`http://psk.testgifts.local/*\` и \`http://testgifts.local/*\`.

## Установка на Windows

1. Скачайте \`vision-local-lan-extension.zip\` с
   \`https://tohaa28.github.io/gifts-layout-workbench-vision/vision-local-lan-extension.zip\`.
   ZIP содержит **только код** расширения, без оригиналов заказов.
2. Распакуйте архив в отдельную постоянную папку на ПК, например
   \`D:\VisionCheckLab\browser-extension\`. Внутри этой папки должны находиться
   \`manifest.json\`, \`service-worker.js\`, \`content-transport.js\`,
   \`vision-order-overlay.js\` и этот README (не выбирайте каталог уровнем выше).
3. В Chrome откройте \`chrome://extensions\`, включите «Режим разработчика»,
   нажмите «Загрузить распакованное расширение» и укажите указанную папку.
4. Убедитесь, что разрешения сайта ограничены **только двумя точными
   тестовыми HTTP-доменами**. Рабочий сайт Gifts и GitHub в разрешениях
   отсутствуют. Не добавляйте wildcard-разрешения.
5. Откройте (или обновите уже открытую) страницу
   \`http://psk.testgifts.local/devorders?status=140\`, авторизуйтесь на
   соответствующих тестовых ресурсах браузера. Панель Vision появится
   автоматически. **Не запускайте одновременно старую закладку**, чтобы не
   было двух копий панели.
6. Сначала нажмите «Проверить строку» только в одном заказе.
   Скачайте анонимный «Отчёт JSON» и проверьте поле \`stage\` при сбое.
   Если требуется — проверьте авторизацию на \`testgifts.local\` в этом же
   профиле Chrome. Разрешение расширения не заменяет серверную авторизацию
   и не гарантирует, что cookies тестового сайта будут приняты.
7. При положительном результате используйте проверку по 10 заказов с
   лимитом 32 исходных файла и явным продлением, затем соберите локальный
   ZIP только экспертно размеченных тестовых оригиналов и импортируйте его
   в \`D:\VisionCheckLab\`.

## Сетевая и техническая модель

- Код расширения упакован локально: MV3 **запрещает удалённые исполняемые
  скрипты**, здесь нет обращения к GitHub Pages для загрузки кода.
- \`content-transport.js\` исполняется как изолированный content script;
  \`vision-order-overlay.js\` отображает статусы поверх таблицы.
- Chrome service worker отвечает только запросам от главного фрейма
  \`psk.testgifts.local/devorders\`, принимает только \`GET\` и только:
  \`/private/order/<цифры>\`,
  \`/ajax/gifts/order?action=makets_popup&oid=<цифры>\`,
  \`/cart/act/mda?oid=<цифры>&id=<цифры>\`.
- Нет POST/DELETE, обхода других доменов, \`/drawing\`, чтения Cookies API,
  публикации макетов и записи данных на сервер.
- Содержимое файла передаётся порционно из фонового процесса Chrome только
  в панель текущей тестовой страницы. Ограничение: 3 МБ на HTML/JSON
  карточки/попапа, 16 МБ на файл, таймаут 15 секунд; пользовательские
  оригиналы не сохраняются в расширении.
- Если сервер требует другой механизм авторизации или изолирует cookies,
  статус останется MANUAL. Не отключайте защиту браузера и не изменяйте
  боевые серверы ради теста.
- Chrome может обновлять модель разрешений; при изменении тестовых URL
  править точный allowlist и заново проверять безопасный контракт.
- JSON отчёты не содержат ID заказа, URL вложений, сырые bytes, cookies.
  Оригиналы ZIP могут быть конфиденциальны: храните **локально**.
