Vision Check · тестовые заказы

Изолированный экспериментальный модуль для таблицы http://psk.testgifts.local/devorders?status=140. Запускается поверх открытой страницы в локальной сети и добавляет результаты к строкам заказов.

Установка закладки запуска

  1. На компьютере, подключённом к тестовой локальной сети, откройте эту страницу установщика.
  2. Перетащите кнопку Vision Check — заказы на панель закладок (Ctrl + Shift + B).
  3. Откройте тестовую таблицу на psk.testgifts.local/devorders?status=140, при необходимости авторизуйтесь.
  4. Нажмите созданную закладку. Vision добавит колонку к распознанным строкам. Скачивание макетов начнётся только после нажатия «Проверить макеты» или «Проверить строку».

Что сейчас проверяется

SVG по исходной векторной геометрии, PNG/JPEG/WebP как вспомогательное растровое исследование. PDF скачивается и распознаётся, но до полноценного разбора векторных операций, цветоделения и физического масштаба помечается MANUAL. CDR/AI/EPS/ZIP также требуют отдельного обработчика.

Можно установить экспертную метку для каждой строки и скачать локальный JSON отчёт. Это пока не полноценный обучающий датасет, поскольку исходные файлы и привязки к заказам в отчёт не включаются.

Без передачи макетов на внешние серверы. Загруженный из таблицы файл обрабатывается внутри браузера на локальном origin; автоматических POST, телеметрии, загрузки на GitHub или сохранения исходных макетов в репозитории нет. Публично размещается только код. Исходные файлы и пользовательские идентификаторы в JSON отчёт не включены.

Для работы необходим браузерный доступ к этой локальной сети. Если реальные ссылки используют другой поддомен или отличаются от тестовых HTML-селекторов, модуль не обходит CORS и не угадывает адреса — потребуется адаптер после осмотра структуры страницы. Политика Content Security Policy тестовой сети также может блокировать запуск внешнего скрипта; в таком случае понадобится локальная установка или расширение браузера.
