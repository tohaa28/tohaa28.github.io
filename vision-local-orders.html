Vision Check · тестовые заказы

Изолированный экспериментальный модуль для таблицы http://psk.testgifts.local/devorders?status=140. Запускается поверх открытой страницы в локальной сети и добавляет результаты к строкам заказов.

Установка закладки запуска

  1. На компьютере, подключённом к тестовой локальной сети, откройте эту страницу установщика.
  2. Перетащите кнопку Vision Check — заказы на панель закладок (Ctrl + Shift + B).
  3. Откройте тестовую таблицу на psk.testgifts.local/devorders?status=140, при необходимости авторизуйтесь.
  4. Нажмите закладку. Vision добавит колонку в таблицу. Начните с кнопки «Проверить строку» для одного заказа. Кнопка «Проверить следующие 10 заказов» читает карточки порциями по 10 без повторного сканирования. После 32 загрузок файлов кнопка «Новый лимит файлов» позволяет продолжить, сохранив результаты, включая частично обработанные заказы.

Локальный тестовый стенд на диске D:

Подготовлен автономный стенд D:\VisionCheckLab: импорт подписанных экспертными метками тестовых ZIP, проверка SHA-256, приватное хранилище оригиналов, SQLite-реестр, журнал ROI и панель только на 127.0.0.1. Данные из локальной сети не отправляются в GitHub.

Скачать установщик стенда для D: (ZIP) Инструкция установки на D:

Распакуйте ZIP, затем запустите PowerShell из извлечённой папки: powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\install-vision-local-lab.ps1. Python 3 с командой py -3 обязателен. Эта страница сама не может записывать файлы на диск D.

Что сейчас проверяется

SVG по исходной векторной геометрии, PNG/JPEG/WebP как вспомогательное растровое исследование. PDF скачивается и распознаётся, но до полноценного разбора векторных операций, цветоделения и физического масштаба помечается MANUAL. CDR/AI/EPS/ZIP также требуют отдельного обработчика.

Можно поставить экспертную метку для каждой строки, скачать анонимный JSON-отчёт или локальный ZIP с оригиналами тестовых макетов из размеченных строк. ZIP скачивается только после отдельного подтверждения, максимум 16 файлов по 4 МБ (общий лимит 24 МБ), без загрузки в GitHub.

ZIP содержит manifest.json и исходные тестовые вложения. Метка всей строки ещё не является разметкой конкретного дефектного объекта: для обучения нужны ROI, подтверждённый масштаб, хеши источников и независимая контрольная выборка. Не размещайте ZIP в публичных репозиториях.

Если таблица не распознана, кнопка «Диагностика таблицы» создаёт JSON только со счётчиками строк и ссылок, без заказных номеров, адресов вложений и исходных файлов. Его можно использовать для настройки адаптера.

Без передачи макетов на внешние серверы. Загруженный из таблицы файл обрабатывается внутри браузера на локальном origin; автоматических POST, телеметрии, загрузки на GitHub или сохранения исходных макетов в репозитории нет. Публично размещается только код. Исходные файлы и пользовательские идентификаторы в JSON отчёт не включены.

Доступность файлов проверяется через /private/order/<номер> → makets_popup → /cart/act/mda. Между psk.testgifts.local и testgifts.local браузер может требовать разрешённый CORS; неподдерживаемая авторизация приводит к MANUAL, а не обходится. Эталонные конструкторы /drawing не считаются клиентскими макетами.

Для работы необходим браузерный доступ к этой локальной сети. Если реальные ссылки используют другой поддомен или отличаются от тестовых HTML-селекторов, модуль не обходит CORS и не угадывает адреса — потребуется адаптер после осмотра структуры страницы. Политика Content Security Policy тестовой сети также может блокировать запуск внешнего скрипта; в таком случае понадобится локальная установка или расширение браузера.
